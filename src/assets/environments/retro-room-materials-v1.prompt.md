# Gamer Room Materials

Created with the built-in image generation tool as two separate tileable bitmap textures.

- `retro-oak-veneer-v1.png`: flat, evenly lit scan of a continuous medium-light oak veneer sheet with horizontal fine grain, pores and subtle satin-varnish wear. No boards, seams, objects, shadows or baked highlights. For a 1990s desk and wardrobe.
- `retro-curtain-twill-v1.png`: flat, evenly lit scan of burgundy brick-red cotton twill with visible warp, weft and herringbone threads. Matte vintage curtain cloth, without folds, seams, objects or baked shadows; the model supplies those details in 3D.

Base color maps use sRGB. Relief maps reuse the image data in linear color space. Furniture UVs follow physical dimensions; door panels rotate the grain vertically. Curtains use separate pleated geometry, sewn hems, rings and a metal rod.
